# SaiceControl - Sistema de Análisis Microeconómico 🚀

![Saice Tarijeño](https://img.shields.io/badge/Status-Project_Ready-brightgreen)
![Aesthetics](https://img.shields.io/badge/UI-Antigravity_Premium-ff3e3e)
![PWA](https://img.shields.io/badge/Type-PWA-00f2ff)

**SaiceControl** es un sistema web avanzado diseñado para la resolución y análisis de modelos microeconómicos aplicados a emprendimientos gastronómicos (específicamente el Saice Tarijeño). Este sistema permite automatizar cálculos complejos de oferta, demanda, equilibrios, elasticidades y optimización de utilidades.

## ✨ Características Principales

-   **Resolución Paso a Paso**: Desglose detallado de 11 pasos para competencia perfecta y 10 para monopolio.
-   **Interfaz Antigravity**: Diseño premium con glassmorphism, modo oscuro profundo y animaciones fluidas.
-   **Persistencia Total**: Los datos se guardan automáticamente en el navegador (`localStorage`), permitiendo retomar el trabajo en cualquier momento.
-   **Responsive Design**: Optimizado para dispositivos móviles, tablets y escritorio. Navegación fluida tipo app móvil en smartphones.
-   **Herramientas de Exportación**: Exporta tus resultados a PDF o Word con un solo clic.
-   **Integración OCR**: Permite pegar capturas de pantalla o datos de Excel directamente para su procesamiento automático.

## 🛠️ Tecnologías Utilizadas

-   **HTML5 / Semantic HTML**
-   **Vanilla CSS3** (Variables, Flexbox, Grid, Glassmorphism)
-   **JavaScript (ES6+)**
-   **Chart.js**: Visualización dinámica de curvas de oferta, demanda y utilidades.
-   **MathJax**: Renderizado profesional de fórmulas matemáticas en LaTeX.
-   **Tesseract.js**: Procesamiento de imágenes para extracción de datos (OCR).
-   **PWA (Service Workers)**: Funcionamiento offline e instalación como aplicación de escritorio/móvil.

## 🚀 Instalación y Uso

1.  Clona este repositorio:
    ```bash
    git clone https://github.com/tu-usuario/saice-control.git
    ```
2.  Abre `index.html` en cualquier navegador moderno.
3.  ¡Listo! No requiere servidor (aunque funciona perfectamente en XAMPP/Apache).

## 📊 Módulos Incluidos

1.  **Competencia Perfecta**: Análisis de equilibrio y punto óptimo de utilidad.
2.  **Competencia Imperfecta (Monopolio)**: Cálculo de costo social mediante integrales.
3.  **Elasticidad**: Sensibilidad de la demanda ante cambios de precio.
4.  **Punto de Equilibrio**: Determinación de volúmenes mínimos de venta.
5.  **Punto de Indiferencia**: Comparación de alternativas de producción.
6.  **Capacidad de Producción**: Análisis de escalabilidad y utilidades incrementales.
